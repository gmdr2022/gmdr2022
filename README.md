## How I work

I define what a product needs to do, how it should behave when something fails, and what evidence supports each release. My work on **Release Evidence** and **Local-first Checklist** explored those ideas through deterministic release manifests, atomic local writes, and explicit recovery.

In Wissian, I focus on clear access boundaries, auditable operations, and keeping the code, deployment, and recovery under the product owner’s control.
